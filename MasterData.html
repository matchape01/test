📋 Consignes génériques
ref_consignes_type.js — REF_CONSIGNES_TYPE — colonnes : id, valueFr, valueEn, descriptif, placements, actif, types
Import des consignes génériques
Importe un fichier Excel exporté depuis cet onglet (feuille « Consignes »). Les lignes avec un ID existant permettent de modifier le texte, les placements, les types — mais jamais l'ID ni le statut Actif. Les lignes sans ID existant créent une nouvelle consigne (Actif = NON par défaut). Aucune suppression n'est effectuée.

Les placements déterminent dans quelle section chaque consigne apparaîtra automatiquement :
Avant / Pendant / Après → Consignes helpers  |  Logistique → Informations logistiques  |  Spécifique → Besoins logistiques spécifiques  |  Participant → Instructions participants
Types : restreint la consigne à certains types d'ateliers (vide = tous les types).
Actif : décoché = consigne désactivée globalement pour tous les ateliers.
